## 5. Vhost TLS

Instalado `deploy/zonagris.pruebapublica.com.conf`.

Incidencias y resolución:

1. El primer `nginx -t` falló porque el vhost repetía `ssl_protocols` y `ssl_prefer_server_ciphers`, ya incluidos en `options-ssl-nginx.conf`.
2. Se restauró el vhost ACME y Nginx quedó sano.
3. Se corrigió el vhost local eliminando esas dos directivas duplicadas.
4. El segundo `nginx -t` pasó y se recargó Nginx.

Configuración efectiva:

- HTTP 301 a HTTPS.
- TLS 1.2/1.3 mediante `options-ssl-nginx.conf`.
- **DNS-only:** no se incluye `cf-origin.conf`, porque exige certificado cliente de Cloudflare.
- HSTS, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, CSP.
- Raíz `/var/www/atlas-zonagris/current`.
- No se tocó la configuración TLS global.
