# Código de conducta

Este proyecto trata incidentes y atribuciones políticas. El desacuerdo es normal; el respeto no es opcional.

- Discute el dato y la fuente, no la identidad de quien participa.
- No publiques datos personales, amenazas ni acusaciones sin evidencia.
- No uses el repositorio para coordinar campañas de acoso.
- Acepta correcciones documentadas y corrige las propias.

El incumplimiento puede llevar al bloqueo del repositorio. El criterio final es del autor del proyecto.
